herdr-app is the Herdr window: what the person sees, in spaces, tabs and panes.
herdr-core (hc) runs every terminal in it. To run, read, talk to and wait on
programs and agents (any automation), use hc: hc --agent-help.
Use herdr-app only to change what's on the person's screen.

You run in a terminal: $HC_TERMINAL_ID.
  herdr-app ls        spaces > tabs > terminals, each with its pane id
  herdr-app status    what's shown now, and any errors

Show something to the person
  herdr-app do tab.new --name "fix login" --argv '["claude"]' --task "look at the login bug"
  herdr-app do pane.split --direction right --pane p12     a shell beside pane p12
  herdr-app do space.new --name api --folder ~/api         --machine vps: on that machine
  herdr-app do agent.focus --terminal t7                   show an agent
  herdr-app commands                                       every command and its arguments

Rules
- Herdr misbehaving? herdr-app feedback "<what happened>": the person reviews and sends it.
- New spaces and tabs are shown at once: only make them when asked.
- Every space and tab has a name you pick; there are no default names.
- A terminal started with hc shows up when it carries the labels
  herdr.space=<id> and herdr.tab=<id> (hc run --label ...); else it stays out.
- Changing how Herdr looks or works (layouts, keys, panels): read
  ~/.config/herdr-app/AGENTS.md first.
